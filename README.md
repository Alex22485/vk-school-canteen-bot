# 🍽️ VK School Canteen Bot

Бот для заказа питания в школьной столовой (платформа VK).

## 📋 Функционал

- ✅ Регистрация пользователей с выбором роли (родитель/ученик, учитель, кухня)
- ✅ Заполнение профиля (город, школа, класс, имя ребёнка)
- ✅ Создание меню для сотрудников кухни
- ✅ Просмотр меню для родителей и учеников
- 🔄 Система заказов (в разработке)
- 🔄 Админ-панель (в разработке)

## 🛠️ Технологии

- Node.js
- VK API (Long Poll)
- SQLite (better-sqlite3)

## 🚀 Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/Alex22485/vk-school-canteen-bot.git
cd vk-school-canteen-bot

# Установка зависимостей
npm install

# Настройка переменных окружения
cp .env.example .env
# Отредактируйте .env (вставьте ваш VK_ACCESS_TOKEN и VK_GROUP_ID)

# Запуск бота
npm run dev
```
